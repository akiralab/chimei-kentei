# 問題バンク生成（data/build_questions.py）

デジタル庁 アドレス・ベース・レジストリ 全国 町字マスター 2026-09-25 版（CC BY 4.0）を加工して
`public/questions/abr20260925/` に問題バンク JSON を書き出す。外部ライブラリ不使用（標準ライブラリのみ）。

```sh
npm run build:questions                      # = python3 data/build_questions.py
python3 data/build_questions.py --abr-dir <dir> --out-dir <dir>   # 入出力を差し替える場合
```

## 入力（`~/workspace/abr-data/processed/`）

- `abr_city_reading.csv`（1,892 行）… 市区町村＋政令市の区。`ward` 非空＝政令市の区
- `abr_name_reading.csv`（441,539 行）… `level` = 市区町村 / 大字・町 / 小字

## 出力（型は `src/engine/types.ts` の `Question` / `BankMeta`。`ensure_ascii=False`・インデントなし・キー順は宣言順）

- `easy.json` … 市区町村 1,741 件（id 昇順）
- `difficult/{prefCode}.json` … 大字・町 107,681 件を 47 都道府県に分割（id 昇順。最小 沖縄県 665／最大 愛知県 6,743）
- `meta.json` … dataVersion / generatedAt / source / prefectures[47] / cities[1,741]

## 前処理ルール（設計 §4）

- **a** `(pref, city)` で一意化。政令市は区の行をまとめて 1 市、郡名は使わない。政令市の `lgCode` は区コードの
  先頭 4 桁＋`'0'`＋全国地方公共団体コードの検査数字（6,5,4,3,2 加重和 → 11−余り、10 以上は 1 の位）。例 札幌 `011002`／川崎 `141305`。
- **b** 末尾 1 文字（市区町村）を `suffix` に分離し、読みからも シ/ク/チョウ|マチ/ソン|ムラ を外す。剥がせなければ例外で停止。
- **c** difficult は `level=='大字・町'` かつ `n_readings=='1'` かつ `kana_small_suspect=='False'` の行のみ。
- **d** 先頭の冠「大字」「字」を外す。読みが オオアザ/アザ のどちらで始まっても外す（どちらでもない 368 件は漢字のみ）。
- **e** 幹が漢字（々・〆 を含む）のみで構成される行だけ残す（数字・カナ・記号を含む 11,987 件を除外）。
  ほか複数読み 596 件・`kana_small_suspect` 5,672 件・空 1 件を除外（`level=='大字・町'` 127,894 → ルール c 通過 121,626）。
- **f** 丁目は対応表で分離済みのため何もしない。**g** `status_flg` は対応表に無いため何もしない。
- 同一 `lgCode`・同一 `display` の重複は、`answer` が一致すれば 1 件に集約（1,715 件を除外）。
  `answer` が割れて正解を一意にできない 115 display（242 行）はキーごと全件落とす。

# 地図データ（data/build_geo.py）

総務省統計局 e-Stat 境界データ 2020 年国勢調査 小地域（shape, 世界測地系緯度経度）を加工して
`public/geo/` に地図 GeoJSON と市区町村統計を書き出す。型は `src/engine/types.ts` の「地図・統計（v1）」節
（`MunicipalityFeatureProps` / `PrefectureFeatureProps` / `MunicipalityStats`）。

```sh
cd data && uv sync                  # 初回のみ（geopandas / shapely / pyogrio / pandas）
cd data && uv run python build_geo.py
cd data && uv run python build_geo.py --prefs 1,42 --out-dir /tmp/geo   # 一部の県だけ試す
```

## 水面調査区（HCODE=8154）は除外する

全国 232,019 小地域の `HCODE` は `8101`（通常の調査区）231,668 件と `8154`（水面調査区）351 件の 2 値のみ。
**8154 は面積・人口・世帯の集計からもポリゴンからも除く。**公称面積との比較で明らかに近いため。

| 市 | 公称 | 8154 を含む | 8154 を除く（採用） |
|---|---|---|---|
| 千葉県匝瑳市 | 101.52 km² | 101.61 (+0.09) | 101.61 (+0.09) ※水面調査区なし |
| 大阪市 | 225.33 km² | 251.98 (**+26.65**) | 220.28 (−5.05) |
| 札幌市 | 1,121.26 km² | 1,121.19 (−0.07) | 1,121.19 (−0.07) ※水面調査区なし |

水面調査区を持たない匝瑳市・札幌市は `AREA` の合計がそのまま公称面積と ±0.1 km² で一致する。
大阪市のように港湾を抱える市だけが分かれ、含めると +26.65 km²、除くと −5.05 km²。名古屋市も同様（−3.27 km²）で、
**除いたほうが一桁近い**。残る過小は、埋立地の一部が水面調査区に含まれているため（`--keep-water` で再現できる）。
人口への影響は全国で 23 人（水面調査区に住む船上生活者等）。

## ジオメトリの処理

1. **`make_valid`** で無効ポリゴンを直す（全国 130 件）。`buffer(0)` は面を削るので使わない
2. **`set_precision(1e-4)` で格子にスナップしてから dissolve する。** e-Stat の小地域は隣接ポリゴンの境界座標が
   完全一致しないため、そのまま溶かすと市区町村ポリゴンの内部に幅 cm 級のスリーバー穴が大量に残る。
   北海道では穴 19,916 個で、1 穴＝最低 4 頂点が削れないので `coverage_simplify` が効かなくなる
   （tolerance をいくら上げても 161,579 頂点で飽和）。スナップ後は同じ tolerance で 20,625 頂点まで落ちる
3. 残った **0.01 km² 未満の穴を埋める**（全国 16,843 個）。実在の飛び地（例 和歌山県北山村 48 km²）は閾値よりはるかに大きいので消えない
4. 簡略化は **`shapely.coverage_simplify`**（面の被覆の共有境界を保つ）。座標は小数 4 桁（≒11 m）に丸め、
   丸めで重なった連続点をつぶす。統計の代表点だけ 5 桁

### tolerance は県ごとに自動調整する

下限 **0.002 度（≒220 m）**から、1 ファイル 300 KB に収まるまで 1.5 倍ずつ上げる。
引き上げが要るのは **北海道だけ（0.00675）**で、残る 46 県は下限のまま。
ポリゴン面積の誤差は中央値 0.25%・最大 2.9%（小値賀町などの離島の町）。

### japan.json は「簡略化済みの市区町村」から作る

生の市区町村ポリゴンを溶かして全国の被覆にすると、**県境の座標が県ファイル間で一致しない**（`coverage_is_valid` が False）。
GEOS は潰せない辺を残すので、関東 10 県だけでも 26,000 頂点で飽和し、全国では 150,000 頂点＝2.9 MB になった。
県内で先に簡略化してから溶かすと、不一致の元になる細かい頂点が先に消え、全国 47 県が 12,000 頂点まで落ちる。

- 15 km² 未満の島を落とす（全国 17,373 個）。沖縄本島・宮古島・石垣島・佐渡・隠岐島後・五島福江島・奄美大島・小笠原父島は残る
- 20 km² 未満の穴を埋める（境界未定地など 2,590 個）
- tolerance は 0.006 度から 1.5 倍ずつ上げるが、**上限 0.03 度（≒3.3 km）で打ち切る**。
  上の理由で coverage_simplify は 9,000 頂点付近で飽和しており、それ以上上げてもサイズは減らず形だけ崩れる
  （0.0683 度では沖縄県の面積が −21% になるのに 173 KB までしか縮まない）
- 結果は **188 KB**で、目標の 150 KB には届かない。県境は隣り合う 2 県が別々に持つため頂点が二重に乗るのが主因。
  面積誤差は中央値 0.41%、最大は沖縄県 11.8%・香川県 7.5%（どちらも落とした小島のぶん）
