# 地名読み検定「この地名、読めますか」

難読地名をひらがなで書いて答える、答案用紙風の 10 問テスト。

- ウェブ版: https://akiralab.github.io/chimei-kentei/
- iOS 版: https://apps.apple.com/jp/app/id6830130673
- 問い合わせ: https://akiralab.github.io/chimei-kentei/support.html

## このリポジトリについて

ウェブ版を配信するための、ビルド済みファイルの置き場。中身は更新のたびに自動で置き換わる。

ソースコードはここには無い。Issue と Pull Request は受け付けていないので、連絡は上の問い合わせ先へ。

## 出典

- 出題: デジタル庁「アドレス・ベース・レジストリ」（[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/deed.ja)）を加工して利用（読みの正規化・難易度の判定・出題の抽出）
- 人口・地図: 総務省統計局 e-Stat（2020 年国勢調査）
- 難易度の判定: KANJIDIC2（EDRDG, CC BY-SA 4.0）
